# Przykłady demonstracyjne

Samodzielne, uproszczone przykłady przygotowane dla tego portfolio. Pokazują sposób podejścia do problemu, a nie kod wdrożonych modułów.

- `validation.py`: sprawdzenie ilości produktu i obliczenie wartości energetycznej.
- `availability.js`: wykrywanie nakładających się przedziałów czasu.
- `identifier.php`: losowy identyfikator bez danych osobowych; sam identyfikator nie jest zabezpieczeniem dostępu.

Dane wejściowe w przykładach są fikcyjne. Identyfikatory zamiast nazwisk ograniczają dane bezpośrednio identyfikujące; nie oznacza to automatycznie pełnej anonimizacji systemu.
